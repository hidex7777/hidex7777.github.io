## 今後の予定

### マーブリング液版の背景作品（`src/sketches/` に追加）

マーブリング液に絵の具を落とし、尖ったものでつつくと、ぱっと広がる不思議な感じ（水と油が反発するような）。構図は真上から。

- 「数学的マーブリング」で作る。流体の計算はしない。
  - 一滴落とすと、そこにあった模様が面積を保ったまま外側へ押し広げられる。点 P は、滴の中心 C・半径 r に対して C + (P − C)·√(1 + r²/|P − C|²) へ動く。
  - 絵の具同士は混ざらず、境目がくっきり残る。
  - ドラッグ（マウス・指）で櫛を引くと、模様がその線に沿って引きずられ、羽根模様になる。
  - 模様を多角形として描くので、GPU なしでも軽く、拡大してもにじまない。
- 色は `ink.js` と同じ10色のパレット。
- クリック＝一滴、ドラッグ＝櫛。自動でもときどき滴が落ちる。
- `prefers-reduced-motion` のときは静止画。
- できたら `src/main.js` の一覧に加え、`ink` とランダムに切り替わるようにする。

### 小さな調整（後で詰める）

- **トップの名前の太さ**：等幅フォントが端末ごとに違うため、PC の Chrome では太め、Android では細めに見える。そろえるなら、等幅のウェブフォントを1書体だけ読み込む。
- **サイトの説明文**：`src/_data/site.json` の description は仮の文。検索結果や SNS のリンクカードに出る。
- **OGP 画像**：まだない。SNS で共有したときのカード用に、1枚用意する。
